# Mongolian ger photographs

These folders are empty on purpose. No product photographs were supplied, and travel or destination pictures must not be used as product photos.

Upload the manufacturer's files using the names below, then add each full web path to `data/mongolian-ger-manifest.json` in the `files` array. The store shows a photograph only when that path is listed in the manifest. Until then, the product page says the photographs are waiting for the manufacturer's upload.
